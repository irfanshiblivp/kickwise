# **App Name**: Kickwise 2026

## Core Features:

- Academic Profile Management: Custom authentication system where students can register with their academic year (2nd, 3rd, 4th), department, and credentials.
- KICKWISE Branding Portal: An high-fidelity landing experience showcasing Dhruva 2026 and CEM Munnar branding alongside the official tournament and union logos.
- Dynamic Round Tracker: Visual match dashboard organized by rounds (1, 2, 3, and Knockout) featuring nation flags, time, venue, and nation names.
- Admin Tournament Hub: Admin control interface to unlock specific rounds, update match results, add matches, and manage official tournament status.
- Score Forecast Tool: AI-powered tool to analyze match history and assist users in making more informed score predictions for unlocked matches.
- Automated Leaderboard Logic: Points processing engine that awards 10 points for exact scores and 5 points for correct outcome, updating the live standings automatically.
- Admin-to-User Notification Panel: A dedicated communication bridge allowing admins to broadcast messages and updates directly to user dashboards.

## Style Guidelines:

- Primary color: Vibrant Azure Blue (#3D8BFF) representing global athletics and energy. Background color: Deep Obsidian (#141A20) for a sleek, premium digital feel. Accent: Electric Indigo (#847DFF) to highlight interactive UI components and call-to-actions.
- Headline font: 'Space Grotesk' for a computerized, tech-forward sporting vibe. Body font: 'Inter' for neutral, machined clarity, especially for tournament data and scores.
- Geometric, high-stroke weight icons representing sports and college departments, styled with subtle glowing neon borders.
- Modular bento-grid layout for match listings, ensuring critical tournament information and branding elements like logos remain in fixed focus.
- Fluid 'smooth-sweep' transitions when rounds are unlocked and celebratory 'pop' effects when user points increment on the leaderboard.
